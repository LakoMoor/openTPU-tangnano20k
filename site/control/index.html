Как запустить настоящую генерацию?

Модель и соответствующий образ на SD-карте должны быть подготовлены заранее. Отключите порт в этой панели перед запуском CLI:

python tools/tang/chat.py MODEL_DIR --port COM6 --image SMOL135.IMG --wformat fp4 --head-format int8

Замените MODEL_DIR, COM6 и параметры формата на свои. Статический GitHub Pages не выполняет Python-компилятор.
